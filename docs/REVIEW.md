# บันทึกการตรวจรุ่นปัจจุบัน — 1 พฤศจิกายน 2569

## ขอบเขต

ตรวจโค้ดและ flow ใน DOM จำลองด้วย Vitest, React Testing Library และ jsdom โดยทดสอบซ้ำที่ค่า `window.innerWidth` 390 และ 1366 พิกเซล ครอบคลุมหน้าแรก ความต้องการ จุดสนใจ แผน แผนที่ รายละเอียดจุด และ QR

**jsdom ไม่มี layout engine:** การตั้งความกว้างดังกล่าวไม่ใช่การตรวจภาพมือถือหรือคอมพิวเตอร์จริง ยังไม่ยืนยันการจัดวาง ข้อความล้น contrast หมุดที่ซ้อนกัน หรือขนาดเป้าสัมผัสจากภาพหน้าจอ browser automation ในเซสชันก่อนถูกหยุดเพราะตรวจ URL ของ Chrome ไม่ได้ รอบนี้จึงไม่ใช้เครื่องมือเดิมซ้ำจนขัดจังหวะงาน และใช้การตรวจทดแทนตามที่ผู้ใช้อนุญาต

## การตรวจอัตโนมัติ

ผลรันล่าสุด: **24/24 tests ผ่าน**, `npm run build` ผ่าน, production preview ตอบ **HTTP 200** สำหรับ HTML และ assets ทั้ง **10 ไฟล์** (ภาพ 8, CSS 1, JavaScript 1)

- ทดสอบเลือกความต้องการ กรองจุด เพิ่ม/ลบ/เรียงลำดับ บันทึก เปิดกลับ และลบแผน
- ค้นหาและกรองตามหมวดทางการ เปิดรายละเอียดจุดที่ตำแหน่งรอยืนยัน ไม่มีหมุดที่เดาตำแหน่ง
- ตรวจว่าใช้ภาพแผนที่ทางการ มีหมุดที่ทบทวน 9 จุด ไม่เหลือ SVG แผนผังเก่าหรือเส้นทาง polyline
- สร้าง QR จริงเป็น PNG data URL เปิดรายละเอียดผ่านปุ่มและ deep link; ยังไม่ได้สแกนด้วยกล้องโทรศัพท์จริง
- GPS mock ยืนยันว่าไม่เรียกก่อนคลิก รองรับผลสำเร็จ ปฏิเสธสิทธิ์ หาตำแหน่งไม่ได้ และหมดเวลา โดยไม่เก็บพิกัด; ยังไม่ได้ทดสอบ GPS หรือ permission prompt จริง
- ตรวจไฟล์ภาพทั้ง 8 ไฟล์ ขนาด ต้นทาง และ SHA-256 ของแผนที่ตรงกับบันทึกตรวจ
- ใช้ Pillow อ่านและ verify ไฟล์ภาพทั้ง 8 สำเร็จ; ไม่พบไฟล์ภาพเสีย การโหลดผ่าน HTTP ตรวจแยกจากการจัดวางหน้าจอ
- ตรวจ TypeScript และ production build ด้วย `npm run build`

## การแก้ระหว่างตรวจ

- ลิงก์ข้ามไปเนื้อหาคงหน้าเดิม ไม่เปลี่ยน hash แล้วพากลับหน้าแรก
- รีเซ็ตตัวกรองและคำค้นเมื่อเปิดลิงก์หรือย้อนหน้าด้วยประวัติเบราว์เซอร์
- แก้ intrinsic dimensions แผนที่เป็น 1440×960 ให้ตรงไฟล์จริง
- สคริปต์นำเข้าบันทึกวันตาม Asia/Bangkok และ hash ภาพ แทนวันที่ตายตัว
- ใช้บันทึกตรวจ `map-review.ts` แยกจาก snapshot หากไฟล์แผนที่หรือค่า x/y เปลี่ยน หมุดที่ตรวจไว้เดิมจะไม่ถูกใช้ต่อโดยอัตโนมัติ ต้องตรวจภาพใหม่ก่อน ไม่เพิ่มค่าพิกัดภาคสนาม
- ปรับ README, metadata หน้าเว็บ, ขอบเขตสิทธิ์ภาพ และรายการ ignore ให้ตรงรุ่นล่าสุด

## ยังต้องตรวจด้วยคน/อุปกรณ์จริง

เปิดทั้ง 7 หน้าหลักที่ความกว้างมือถือประมาณ 390 พิกเซล และคอมพิวเตอร์ประมาณ 1366 พิกเซล ตรวจรูป โหลดฟอนต์ ข้อความยาว เมนู ปุ่ม การซูม/เลื่อนแผนที่ และ modal ทั้งโหมดข้อความขยายและคีย์บอร์ด จากนั้นสแกน QR ผ่าน URL ที่โทรศัพท์เข้าถึงได้ และทดลอง GPS จริงบน HTTPS หรือ localhost ที่รองรับ ไม่ถือว่าการ build ผ่านแทนรายการนี้ได้

ไม่มีการตรวจภาคสนามหรือเพิ่ม/คาดเดาพิกัด เส้นทาง ระยะทาง เวลาเดิน รอบแสดง คิว หรือความเหมาะสมกับรถเข็น

## ก่อนเผยแพร่ source

ตรวจรายการไฟล์ทั้งหมดและค้นหารูปแบบ private key, GitHub token, AWS access key, Slack/Google API token และการกำหนด credential เป็น string ไม่พบรายการที่เข้าเงื่อนไข ไม่พบ `.env`, key/certificate, database หรือ log ในรายการที่จะเผยแพร่ โดย `node_modules`, `dist`, npm cache และ TypeScript build cache ถูก ignore การสแกนแบบ pattern ไม่ใช่หลักประกันว่าตรวจจับ secret ได้ทุกชนิด

ตรวจ URL ต้นทางของภาพทุกไฟล์และบันทึกคำยืนยันของผู้ใช้ว่าการอนุญาตครอบคลุม repository public ไว้ใน `ASSET_RIGHTS.md` ไม่เปลี่ยน visibility ของ repository และไม่ force-push
